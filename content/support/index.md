# Support

Choose the channel that matches your request. Public questions help other users; security details
must stay private.

## Questions and community help

Ask usage, conversion, and design questions in
[GitHub Discussions](https://github.com/Strukturpiloten/boxferry/discussions). Include the BoxFerry
version, input and output kinds, target versions, and diagnostic rule codes. Never paste secrets,
private environment files, or raw runtime data.

## Bugs and feature requests

[Open a GitHub issue](https://github.com/Strukturpiloten/boxferry/issues/new/choose) with the smallest
reproducible input you can share. For a conversion failure, attach the privacy-safe generated error
report instead of raw production files.

## Private security reports

Do not publish suspected vulnerabilities in an issue or discussion.
[Report a BoxFerry vulnerability privately on GitHub](https://github.com/Strukturpiloten/boxferry/security/advisories/new).
GitHub sign-in is required. The report opens a private conversation with the maintainers.
