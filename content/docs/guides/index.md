# Conversion guides

BoxFerry conversions are N:N. Each supported route receives its own copyable, executable guide.

| Input         | Compose output                                    | Quadlet output                                    |
| ------------- | ------------------------------------------------- | ------------------------------------------------- |
| Compose input | [Compose to Compose](convert/compose-to-compose/) | [Compose to Quadlet](convert/compose-to-quadlet/) |
| Quadlet input | [Quadlet to Compose](convert/quadlet-to-compose/) | [Quadlet to Quadlet](convert/quadlet-to-quadlet/) |

Compose-input guides will distinguish preserved interpolation expressions from explicit
`--interpolate` processing. Quadlet-input guides will not present interpolation as applicable.
